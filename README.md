# ⌨️ 영단어 낙하 타이핑 게임 (English Word Drop)

위에서 영어 단어가 블록으로 떨어집니다. 아래 칸에 **한글 뜻**을 입력하고 Enter!
맞히면 펑 터지고, 놓치면 왼쪽에 벽돌처럼 쌓입니다. **벽돌 10개면 게임오버.**

## 특징
- **10단계** 난이도·속도 (입문 → 고급), 시작 시 단계 선택
- **여러 뜻 허용**: 뜻이 여러 개인 단어는 *아무 뜻이나* 맞히면 정답 (예: `run` → 달리다/뛰다/운영하다)
- 게임오버 시 **놓친 단어 10개의 뜻**을 한눈에 복습
- **모바일·데스크탑** 모두 지원 (반응형, 모바일 키보드 자동)
- 외부 라이브러리·API **0개**, 100% 오프라인 단일 파일

## 플레이
- 온라인: GitHub Pages URL (배포 후 자동 생성)
- 로컬: `index.html` 더블클릭

## 파일
- `index.html` — 게임 본체 (HTML/CSS/JS)
- `words.js` — 레벨별 단어 데이터 (영단어 : 허용 한글 뜻 배열)
